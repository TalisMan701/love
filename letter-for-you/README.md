# Любимой, с любовью

Интерактивный подарок на шестую годовщину: письмо, шесть признаний и сертификат Lamoda на 10 000 ₽. Молочная, пудровая и винная палитра, объёмный конверт, переворачивающиеся карточки, финальная восковая печать. Музыка включена по умолчанию: запускается автоматически, если браузер разрешает, иначе — при первом нажатии или действии с клавиатуры. Выключение звука сохраняется до перезагрузки страницы. При скрытии вкладки музыка приостанавливается. Все взаимодействия доступны с клавиатуры; настройка уменьшения движения учитывается.

## Запуск

Из этой папки: `npm start`. Открыть `http://127.0.0.1:4173`.

Сайт не требует установки зависимостей или сборки. Готовые файлы находятся в `dist`.

Для просмотра без сервера откройте `alina.html` обычным двойным нажатием. В этом файле уже собраны все стили, интерактивность и музыка; интернет нужен только для загрузки шрифтов, без него используются системные шрифты. После изменения исходников обновите этот файл командой `node build-preview.mjs`.

Музыкальный фон — «Гимнопедия № 1» Эрика Сати, фортепиано Robin Alciatore (Musopen). Запись хранится локально в `dist/media/gymnopedie-no-1.mp3`, играет по кругу и продолжается при переходах между экранами. Источник и сведения о свободном использовании — в `dist/media/CREDITS.md`.

При открытии появляется прелоадер с сердечком. Он ждёт стили, шрифты Lora и Nunito, загрузку и декодирование изображений `<img>` и готовность музыки к непрерывному воспроизведению. Нынешние иллюстрации и иконки созданы в CSS и встроенном SVG и не требуют отдельных загрузок. Максимальное ожидание — 8 секунд от начала загрузки документа; ошибки ресурсов не блокируют письмо. Запуск музыки не требуется для завершения загрузки, поэтому ограничения автозапуска на телефоне не задерживают переход. Без JavaScript прелоадер скрыт. При уменьшении движения сердечко и точки статичны.

## Перед вручением

Тексты признаний — предложенный черновик. Их можно заменить в `dist/config.js`.

Данные сертификата находятся в объекте `certificate` в `dist/config.js`: `code`, `pin`, `amount` и `activationUrl`. Сейчас указаны временные код `123456789` и PIN `1234`, номинал — 10 000 ₽. Перед вручением замените код и PIN (оставляя их строками в кавычках). По просьбе автора пометка о временных данных в интерфейсе не отображается. Затем обновите `alina.html` командой `node build-preview.mjs`.

В финале можно скопировать код и PIN по отдельности. Если браузер не разрешает доступ к буферу обмена, значение выделяется для ручного копирования. Кнопка «Активировать на Lamoda» открывает заданную ссылку в новой вкладке; код и PIN автоматически не отправляются. Не добавляйте действующие данные в открытый репозиторий или общедоступный сайт.
