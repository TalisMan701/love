# Любимой, с любовью

Статический сайт на HTML, CSS и JavaScript. Исходники и готовые файлы для публикации находятся в `letter-for-you/dist/`; установка зависимостей и сборка для сервера не нужны.

Локальный просмотр:

```powershell
cd letter-for-you
npm start
```

Открыть `http://127.0.0.1:4173`.

Целевой адрес: **https://artkompaneets.ru**. Сервер Aeza: `77.221.154.156`, Ubuntu, Caddy. Настройка сервера, DNS и автодеплоя описана в [DEPLOY.md](DEPLOY.md).

Изменения сайта вносятся в `letter-for-you/dist/`. После настройки GitHub Secret `DEPLOY_SSH_KEY` каждый push в `main` запускает проверки и публикацию. Код и PIN подставляются при деплое из GitHub Actions Secrets `CERTIFICATE_CODE` и `CERTIFICATE_PIN`; ведущие нули сохраняются. Если оба секрета не заданы, остаются временные значения. После изменения секретов нужно запустить **Actions → Deploy to Aeza → Run workflow**.

Настоящие код и PIN не записываются в исходники или Git, но после публикации доступны посетителям сайта. Подробности и локальная подготовка из `.env` описаны в [DEPLOY.md](DEPLOY.md).
