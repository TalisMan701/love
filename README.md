# Любимой, с любовью

Статический сайт на HTML, CSS и JavaScript. Исходники и готовые файлы для публикации находятся в `letter-for-you/dist/`; установка зависимостей и сборка для сервера не нужны.

Локальный просмотр:

```powershell
cd letter-for-you
npm start
```

Открыть `http://127.0.0.1:4173`.

Целевой адрес: **https://artkompaneets.ru**. Сервер Aeza: `77.221.154.156`, Ubuntu, Caddy. Настройка сервера, DNS и автодеплоя описана в [DEPLOY.md](DEPLOY.md).

Изменения сайта вносятся в `letter-for-you/dist/`. После настройки GitHub Secret `DEPLOY_SSH_KEY` каждый push в `main` запускает проверки и публикацию. Действующие данные подарочного сертификата нельзя размещать в этом публичном репозитории; текущие код и PIN — временные значения.
